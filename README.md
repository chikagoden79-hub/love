# Я тебя люблю ❤️ — версия 2 (в обе стороны, бесплатно)

Одна кнопка-сердце. Нажимаешь, и на другом телефоне приходит уведомление «❤️ Я тебя люблю ❤️». Работает в обе стороны (iPhone и Android), даже когда приложение закрыто.

```
Телефон ──▶ Supabase Edge Function ──▶ push-сервис Apple / Google ──▶ другой телефон
                    │
                    └──▶ база Supabase (подписки телефонов)
Сайт (PWA) — GitHub Pages
```

**Цена: 0 ₽.** GitHub Pages бесплатный. У Supabase на бесплатном плане 500 000 вызовов функции в месяц, а вам хватит пары тысяч. Банковская карта не нужна.

**Что важно знать**
- **iPhone:** нужна iOS 16.4 или новее, и приложение должно быть открыто **с иконки на главном экране**. Из вкладки Safari уведомления не работают.
- **«Засыпание» проекта:** бесплатный проект Supabase засыпает после 7 дней без активности. Против этого есть три защиты: обычное использование, проверка связи при каждом открытии приложения и задача GitHub Actions `keepalive`, которая пингует проект раз в 3 дня. Если проект всё-таки уснул, зайди в панель Supabase и нажми **Restore**. Данные при этом не пропадают.
- **Доставка:** уведомления доставляют Apple и Google. Обычно это занимает секунды, но время не гарантировано. Режимы «Не беспокоить» и «Фокусирование» могут скрыть уведомление.

## Что в архиве

```
site/        → загрузить в GitHub-репозиторий (содержимое папки, в корень)
  index.html  style.css  app.js  config.js  sw.js  manifest.webmanifest  иконки
  keygen.html                 ← генератор ключей (после настройки удалить)
  .github/workflows/keepalive.yml   ← будильник для Supabase
supabase/
  index.ts     → код функции (вставляется в редактор Supabase целиком)
  schema.sql   → таблица (выполняется один раз в SQL Editor)
```

Секреты хранятся **только** в Supabase, в секретах функции: приватный VAPID-ключ и ключ семьи. В `config.js` есть только адрес функции.

---

## Шаг 1. GitHub Pages: сайт

1. github.com → **New repository** → имя `love` → **Public** → Create.
2. **Add file → Upload files** → перетащи **всё содержимое** папки `site` (вместе с папкой `.github`) → **Commit changes**.
   - Если папка `.github` не загрузилась, сделай так: **Add file → Create new file** → в имени напиши `.github/workflows/keepalive.yml` → вставь содержимое файла → Commit.
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → **Save**. Включи **Enforce HTTPS**.
4. Через 1–2 минуты появится адрес `https://ЛОГИН.github.io/love/`. Запиши его.

## Шаг 2. Ключи

1. Открой `https://ЛОГИН.github.io/love/keygen.html` → **Сгенерировать**.
2. Сохрани в заметку три значения: `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `FAMILY_KEY`.

## Шаг 3. Supabase: база и функция

1. **supabase.com** → **Start your project** → войди через GitHub.
2. **New project**:
   - имя `love`;
   - Database Password — нажми Generate и сохрани;
   - Region — **Central EU (Frankfurt)**;
   - → **Create new project**. Создание занимает пару минут.
3. **SQL Editor** (слева) → **New query** → вставь весь файл `supabase/schema.sql` → **Run**. Должно появиться «Success».
4. **Edge Functions** → **Deploy a new function** → **Via Editor**:
   - вместо примера вставь **весь** файл `supabase/index.ts`;
   - имя функции: `love`;
   - → **Deploy function**.
5. Открой функцию `love` → вкладка **Details** (или Settings) → выключи **Enforce JWT Verification** (Verify JWT) → **Save**.
   - Это обязательно, иначе телефоны получат ошибку 401.
   - Защита от этого не слабеет: функция сама проверяет ключ семьи.
6. **Edge Functions → Secrets** → добавь 5 секретов:

   | Name | Value |
   |---|---|
   | `VAPID_PUBLIC_KEY` | из keygen |
   | `VAPID_PRIVATE_KEY` | из keygen |
   | `FAMILY_KEY` | из keygen |
   | `VAPID_SUBJECT` | `mailto:твой@email` (реальный адрес) |
   | `ALLOWED_ORIGIN` | `https://ЛОГИН.github.io` (без `/love` и без `/` на конце) |

   `SUPABASE_URL` и сервисный ключ Supabase подставляет сам, добавлять их не нужно.
7. Скопируй адрес функции со страницы функции. Он выглядит так: `https://ПРОЕКТ.supabase.co/functions/v1/love`.

## Шаг 4. Связать сайт с функцией

1. В репозитории открой `config.js` → значок карандаша → вместо `ВСТАВЬТЕ_URL_ФУНКЦИИ` вставь адрес из шага 3.7 → **Commit changes**.
2. Удали `keygen.html`: открой файл → «…» → **Delete file** → Commit.
3. Вкладка **Actions** → если GitHub спросит, включи workflows → **keepalive** → **Run workflow**. Через минуту должна появиться зелёная галочка.

## Шаг 5. Проверка из PowerShell (необязательно)

```powershell
$URL = "https://ПРОЕКТ.supabase.co/functions/v1/love"
Invoke-RestMethod -Method Post -Uri $URL -ContentType "text/plain" -Body '{"action":"ping"}'
```
Ожидается `ok: True`.

```powershell
Invoke-RestMethod -Method Post -Uri $URL -ContentType "text/plain" -Headers @{Origin="https://ЛОГИН.github.io"} -Body '{"action":"status","key":"ТВОЙ_FAMILY_KEY"}'
```
Ожидается `ok: True` и пустой список `others`.

## Шаг 6. Телефоны

**iPhone:**
1. Открой адрес сайта в **Safari** → «Поделиться» → **«На экран «Домой»»** → Добавить.
2. Запусти приложение **с иконки**. Откроются настройки: вставь ключ семьи (`FAMILY_KEY`) → **Подключить и разрешить уведомления** → Разрешить.

**Android:**
1. Открой адрес в Chrome → ⋮ → **Установить приложение**.
2. Открой приложение с иконки. В настройках вставь тот же ключ семьи → **Подключить**.

Нажми сердце: на втором телефоне придёт «Я тебя люблю ❤️». С него можно ответить тем же.

Ключ семьи удобно передать сообщением и вставить на телефоне мамы, а лучше настроить её телефон самому. После подключения ключ хранится на телефоне, повторно его вводить не нужно.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| «Нет связи с сервером» | Неверный адрес в `config.js`; не выключен **Enforce JWT Verification**; нет интернета |
| «Сервер не разрешил адрес этого сайта» | `ALLOWED_ORIGIN` должен быть ровно `https://ЛОГИН.github.io` |
| «Сервер настроен не полностью» | Не добавлен один из 5 секретов (смотри Edge Functions → love → Logs) |
| «База на сервере недоступна» | Не выполнен `schema.sql`, или проект уснул (Restore в панели) |
| «Неверный ключ семьи» | Ключ на телефоне не совпадает с `FAMILY_KEY` (лишний пробел, не весь скопирован) |
| «Второй телефон ещё не подключён» | Подключи второй телефон тем же ключом |
| «Второй телефон отключился» | На нём удалили приложение или запретили уведомления. Открыть там ⚙︎ → Подключить |
| На iPhone нет кнопки разрешения / ошибка подписки | Приложение открыто не с иконки, или iOS старше 16.4 |
| «Отправлено», но уведомления не видно | «Не беспокоить»/Фокус; Настройки → Уведомления → «Люблю» → Разрешить; проверь интернет у получателя |
| Видна старая версия сайта | Полностью закрой приложение (смахни) и открой снова |

**Сменить ключ семьи** (например, если он утёк): сгенерируй новый в keygen, замени секрет `FAMILY_KEY` и заново подключи все телефоны в ⚙︎.

**Безопасность.** Без ключа семьи функция ничего не отправит. Ключ сравнивается за постоянное время. Подписки принимаются только от push-сервисов Apple, Google, Mozilla и Microsoft. Таблица закрыта от публичного доступа (RLS), к ней есть доступ только у функции.
